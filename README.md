# Día GIS

Sitio web del evento. TanStack Start + React + Tailwind CSS.

## Desarrollo

```sh
npm install
npm run dev      # http://localhost:8080
```

## Producción

```sh
npm run build
npm start        # sirve en el puerto 3000 (variable PORT)
```

## Docker

```sh
docker build -t dia-gis .
docker run -p 8080:3000 dia-gis
```
